# AgentDesk releases

Downloads and the update feed for [AgentDesk](https://github.com/ananmouaz/agentdesk), the
Mac app for running several Claude Code and Codex agents.

- **Download:** [AgentDesk.dmg](https://github.com/ananmouaz/agentdesk-releases/releases/latest/download/AgentDesk.dmg)
  (the latest version; macOS 15 or newer, Apple silicon and Intel). Open the DMG and drag
  AgentDesk to Applications.
- **Updates:** installed apps check `appcast.xml` once a day and offer new versions in the
  app. AgentDesk › Check for Updates… checks now.
- **All versions:** [Releases](https://github.com/ananmouaz/agentdesk-releases/releases).

Every build is signed with a Developer ID and notarized by Apple, so macOS opens it without
warnings. Each update is also signed with the AgentDesk update key, which the app verifies
before installing.

The release workflow in the AgentDesk repository publishes here; nothing in this repository
is edited by hand.
